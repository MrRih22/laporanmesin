## 🚀 Tentang Proyek
**MTC Command Center & Operator Portal** adalah solusi digital modern yang dirancang untuk mengotomatisasi alur pelaporan kerusakan mesin di lingkungan pabrik PT Tatalogam Lestari. Sistem ini menggantikan pencatatan manual dengan pendekatan *real-time ticketing*, integrasi WhatsApp broadcast instan, serta manajemen status pemeliharaan berstandar *Enterprise SaaS*.

---

## 🧰 Tools & Tech Stack yang Digunakan

Proyek ini dibangun menggunakan perangkat dan teknologi modern kelas industri untuk memastikan performa yang cepat, aman, dan responsif di berbagai perangkat (PC, Tablet, Android, iPhone):

### **1. Frontend Development**
* **React.js (Vite):** Pustaka JavaScript utama untuk membangun antarmuka pengguna yang interaktif dan reaktif.
* **Tailwind CSS v4:** Kerangka kerja CSS berbasis utilitas untuk menciptakan desain antarmuka yang bersih, modern, dan responsif.
* **React Router DOM:** Pengelola navigasi halaman dan sistem *Protected Route* berbasis autentikasi.

### **2. Backend, Database & Real-Time Engine**
* **Supabase (PostgreSQL):** Platform backend-as-a-service yang menangani basis data relasional secara aman.
* **Supabase Realtime WebSockets:** Memungkinkan sinkronisasi data instan tanpa perlu *refresh* halaman di Command Center.
* **Supabase Auth:** Sistem autentikasi berbasis token yang aman untuk hak akses staf divisi MTC.

### **3. Deployment & PWA (Progressive Web App)**
* **Vite PWA Plugin:** Mengubah aplikasi web menjadi *Progressive Web App* agar dapat diinstal langsung ke layar utama perangkat seluler (Android & iOS).
* **Netlify / Vercel:** Platform *cloud hosting* berperforma tinggi untuk peluncuran produksi secara global.

### **4. Development Tools & Version Control**
* **Git & GitHub:** Pengelolaan kode sumber, pelacakan versi, dan kolaborasi repositori.
* **Visual Studio Code (VS Code):** *Code editor* utama yang dilengkapi ekstensi pengembangan web modern.

---

## 📱 Fitur Utama Sistem
1. **Formulir Operator Interaktif:** Formulir pelaporan kendala mesin yang bersih, tanpa gangguan *autofill*, dan mudah dioperasikan di perangkat seluler pabrik.
2. **Command Center Dashboard:** Panel pemantauan tiket masuk secara *real-time* lengkap dengan indikator status (Baru/Selesai) dan penghitung otomatis di tab browser.
3. **WhatsApp Broadcast Integration:** Tombol pintas otomatis untuk meneruskan detail kerusakan mesin langsung ke grup WhatsApp tim MTC.
4. **PWA Support:** Dapat diinstal di HP layaknya aplikasi *native* perusahaan.
